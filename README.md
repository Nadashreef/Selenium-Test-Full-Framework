# Selenium Test Automation Framework

A Java-based test automation framework for OrangeHRM, built with Selenium WebDriver, TestNG, and Maven. The project includes UI automation, API testing, database verification, and CI/CD integration.

## Tech Stack

- Java, Selenium WebDriver, TestNG, Maven
- Page Object Model (POM)
- REST Assured for API testing
- Extent Reports and Log4j2
- Jenkins, Docker, and Selenium Grid

## Key Features

- Reusable automation components and page objects
- Data-driven testing and retry mechanism
- Cross-browser and remote test execution
- API testing and database verification
- Automated test execution through Jenkins
- Test reporting and logging
